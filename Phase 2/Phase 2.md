# Phase 2 – Data Collection and Analysis

## Overview

In Phase 2, we collected attack data and analyzed it using Splunk.

## Steps

- Installed Splunk and configured it to receive data.
- Deployed Splunk Universal Forwarder on Metasploitable3.
- Collected SSH login attempt logs.
- Analyzed failed login attempts related to brute-force attacks.
