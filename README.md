# ICS344 Final Project

## Overview

This project demonstrates vulnerability assessment, attack execution, log analysis, and defensive mitigation techniques using Metasploitable3, Kali Linux, Hydra, Splunk, and Fail2Ban.

The project is divided into three phases:

- **Phase 1:** Setup and Service Compromise
- **Phase 2:** Data Collection and Analysis
- **Phase 3:** Defensive Strategy Proposal
